# Luisferbarberia — web estática (Astro)

Web de una página para Luisferbarberia (Alcalá de Henares). Las citas se gestionan en Booksy.

## Comandos

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # genera ./dist (subir a Netlify, Vercel, GitHub Pages...)
npm run preview
```

## Dónde editar

- `src/data/negocio.ts` — enlace de Booksy, teléfono, dirección, horario, precios y reseñas.
- `src/data/galeria.ts` + `src/assets/cortes/` — fotos de los cortes (sustituir por fotos reales).
- `src/assets/hero.jpg` — imagen de portada.
- `src/components/` — secciones de la página.

Las fotos actuales son de stock (Unsplash) y sirven solo de ejemplo.
